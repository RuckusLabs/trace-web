Your first comparison

  1. Copy a reference image and paste it into Trace with ⌘V, or position Trace over a visible reference and press ⌘G to capture the image viewport beneath it. Trace’s own windows are excluded from the capture.
  2. Move Trace over your implementation. Use the arrow keys to align the window and ⌘0 for Actual Size.
  3. Use ⌘I to toggle inversion and ⌘L to toggle 50% image translucence. Matching content blends to neutral gray at 100% window opacity.

Screen Recording permission

Screen Recording permission lets Trace capture other applications. You can still paste a clipboard image without capturing the screen.

  1. Try Capture in Trace. If permission is denied, use the app’s Open Settings action.
  2. In System Settings, go to Privacy & Security → Screen & System Audio Recording and enable Trace.
  3. Relaunch Trace if macOS requests it, then try ⌘G again.

If a capture spans displays, gaps between displays and off-screen areas remain transparent. Trace shows a notice when part of the requested region is uncovered.

Understanding the overlay

Why do matching areas become gray?

Inversion complements the reference image’s colors. With 50% image translucence and 100% window opacity, matching reference and live content blend to neutral gray. Displaced edges remain visible. This is a visual comparison, not an automatic difference detector.

Image translucence and window opacity

⌘L switches the image between 50% and fully opaque. The Window opacity slider in Preferences changes the entire window from 20% to 100%. Lowering it changes the inversion blend, so return it to 100% for the default comparison.

Size and positioning

⌘0 restores the image’s original logical size. Tab tooltips show both point and pixel dimensions. Arrow keys move the window by 1 macOS point; hold Shift for 10 points. Enable Arrow keys require ⌘ to move window in Preferences if you prefer Command-modified movement. Retina display pixels and macOS points are different units.

Click through to your build

Use ⌃⌘L to lock the Trace overlay and pass mouse clicks through to the app underneath. To unlock it, bring Trace to the front using the Dock or Command-Tab, then use the same shortcut. Capture is unavailable while the window is locked.

Tabs, thumbnails, and session history

Each tab has its own undo and redo history. The thumbnail sidebar appears when enabled and there is more than one tab. Images and history are cleared when you quit; preferences and window positions persist. Use Copy if you want to keep an image outside Trace.

Compatibility and updates

The current Trace app requires macOS 26 or later. Updates are managed by the Mac App Store. Trace’s Check for Updates menu opens its store page.

Trace processes screenshots locally without accounts, telemetry, or uploads. Read the privacy policy.
