Release notes

Capabilities documented for the current app.

Current capabilities

  • Capture the image viewport beneath Trace or paste a clipboard image.
  • Compare using inversion and 50% image translucence, with a separate window-opacity preference.
  • Keep multiple reference tabs and switch through the thumbnail sidebar.
  • Undo and redo image changes within each tab during the current session.
  • Align the window with arrow-key nudges, Actual Size, zoom, and Fit Window to Image.
  • Lock the overlay to pass clicks through to the application underneath.
  • Process screenshots locally, with preferences and window positions saved between sessions.

The current app targets macOS 26 and later. The Mac App Store lists the requirements for the version available to download.
