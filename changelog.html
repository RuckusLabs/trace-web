Changelog

What's new in Trace.

v1.0.0 April 2026
New
  • Initial release — Trace is now publicly available for macOS.
  • Screenshot overlay — import any image and overlay it on top of your running app at any opacity.
  • Pixel-level comparison — toggle inversion mode to spot misalignments instantly with ⌘I.
  • Thumbnail sidebar — manage multiple screenshots in a persistent sidebar, switch with ⌘1–⌘9.
  • Tab management — open, close, and switch between comparison tabs using keyboard shortcuts.
  • Light & Dark theme — toggle the app theme with ⌘D to match your design context.
  • 1px nudge & 10px nudge — fine-tune overlay position using ⌘↑ and ⌘⇧↑.
  • Screen recording permission flow — guided setup for macOS screen capture authorization.
v0.9.0 March 2026
New
  • Drag to reposition — drag the overlay freely to align it with any element.
  • Opacity slider — continuously blend the overlay from fully transparent to fully opaque.
  • Capture shortcut — grab a fresh screenshot without leaving your workflow using ⌘G.
Improved
  • Overlay rendering is now composited on the GPU for smoother real-time updates.
  • Permission dialog now links directly to the correct macOS System Settings pane.
v0.8.0 February 2026
New
  • First internal beta — core overlay engine and screenshot capture.
  • Menu bar integration for quick access without interrupting flow.
Fix
  • Fixed a crash on launch when screen recording permission was not yet granted.
  • Fixed overlay flickering when rapidly switching between Spaces.
Removed
  • Removed experimental grid overlay — will return in a future release with snapping support.
