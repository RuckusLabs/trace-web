TRACE / PRIVACY

Privacy Policy

Privacy policy · Updated October 8, 2026

Screenshots stay on your Mac. Trace processes images locally, without accounts, telemetry, or screenshot uploads.

What Trace does

Trace is a screenshot overlay tool for macOS. It captures the area inside its image viewport or accepts an image you paste, so you can compare a reference with content on your screen. Trace has no account system or backend service and makes no network requests itself.

Screen Recording permission

Screen Recording permission allows Trace to capture other applications when you request a screenshot. Trace excludes its own windows from captures. It does not continuously record your screen or upload captured content.

Screenshots and undo history are held in memory for the current app session. Trace does not save those images to its preferences file or restore them after quitting. If you explicitly copy an image to another application, that application controls what happens to its copy.

Clipboard access

Trace checks whether the clipboard contains a readable image to enable Paste. It reads the image when you invoke Paste, and writes an image when you invoke Copy. It does not run a background clipboard monitor or upload clipboard content.

Local preferences

Trace saves preferences and window state, including appearance, window opacity, tips, and window positions. These are stored in a JSON file in Trace’s Application Support directory, inside its app container when sandboxed. Screenshot data and undo history are not saved there.

Data collection and third parties

Trace does not collect personal information, usage analytics, location data, or crash reports through its own telemetry. It contains no third-party analytics, advertising, or crash-reporting SDKs. Its image processing uses Apple system frameworks.

Distribution and updates are handled by Apple through the Mac App Store. Opening the App Store from Trace sends you to Apple’s application; Apple’s own privacy practices apply there.

This website

This marketing website does not include analytics or advertising scripts. It requests Inter font files from Google Fonts; your browser connects to Google to load them. The website host may process standard request information to serve pages. These website requests are separate from the Trace app’s local screenshot processing.
