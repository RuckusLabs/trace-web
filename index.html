Requires macOS 26 or later.

Allow Screen Recording

Trace needs permission to capture your screen. Follow these steps to enable it:

  1. 1Open System Settings ⌘ Space → type System Settings
  2. 2Go to Privacy & Security → Screen & System Audio Recording
  3. 3Toggle Trace on
  4. 4Relaunch Trace if prompted
